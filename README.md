# LinuxTweaks

Practical Linux configuration, troubleshooting and automation collected through daily Linux use, primarily on Fedora and KDE.

The repository includes small scripts, configuration examples and troubleshooting notes developed while solving real workstation issues rather than as programming exercises.

## Highlights

- Fedora and Linux troubleshooting
- Bash configuration and command-line tools
- Bluetooth device discovery and pairing
- Intel graphics, backlight and Wi-Fi fixes
- Firefox and browser configuration
- Font installation and desktop customization
- openSUSE administration notes

## Structure

- `scripts/` - troubleshooting and utility scripts
- `configs/` - shell, editor and browser configuration examples
- `guides/` - short Linux setup and troubleshooting guides
- `notes/` - useful command-line references

## Example projects

### Bluetooth device identification

A Bash/Python utility developed to identify the Bluetooth Classic audio interface of a Flamma FX10 device when KDE exposed it only as an unnamed Bluetooth address.

### Fedora login-loop troubleshooting

Notes and commands for diagnosing SELinux context problems that can cause a Fedora login loop.

### Linux workstation configuration

Reusable Bash, Nano, Firefox and browser configuration used across Linux installations.

## Environment

Primarily tested on Fedora Linux and KDE Plasma, with additional notes for Debian/Ubuntu and openSUSE.

These scripts are personal utilities and troubleshooting references. Review commands before using them on another system.
